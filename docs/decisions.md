# Accepted decisions

Where a decision below contradicts Microsoft guidance, the product requirements won.

- **WinUI 3 + Windows App SDK on .NET 9.** Standard Fluent controls and the system theme
  only; never invent a custom look. The planned move to .NET 10 LTS is a target framework
  rename and nothing more.
- **Files on disk are the source of truth.** `state.json` is disposable: losing or
  corrupting it loses no materials. Basket display names live in state, not in folder
  names, so renaming a basket never breaks a path handed to an agent. Basket naming is
  pinned to `ru-RU` because the UI is Russian.
- **The basket rail is a left list, not tabs.** Up to 10 baskets; the last basket never
  closes; closing goes to the Recycle Bin with confirmation.
- **Confirmations use the native TaskDialog with «Отмена» as the default button.**
  Microsoft guidance calls a Recycle Bin confirmation unnecessary; the product
  requirements demand it.
- **The app lives in the notification area.** Only the very first launch shows the window.
  A second launch shows the running window and exits: one instance, one tray icon, one
  writer of `state.json`.
- **Commands never live only in a context menu**, and an action that asks for confirmation
  gets an ellipsis.
- **Clipboard order is FileDrop → Bitmap → UnicodeText.** Screenshots save as `.png`, text
  as `.txt` (UTF-8, no BOM), a single http(s) line as `.url`, files copy as is, folders
  copy recursively with junctions and symlinks left unexpanded so copying cannot loop.
  Name collisions get the Explorer ` (2)` suffix.
- **A colon in a name is a file name bug on Windows:** NTFS reads it as an alternate data
  stream separator. Display names keep `Пн, 13:02`; file names replace every
  filesystem-invalid character with `-` (`Пн, 13-02.txt`).
- **Rename edits the base name only; the extension is visible and immutable.** Double click
  never renames.
- **No action may be mouse-only:** reorder, rename and every command have a keyboard path.
- **The preview is a panel inside the window, never a separate window.** No preview
  handlers and no WebView2: a COM host and an extra attack surface are not worth it. Large
  text is read from the beginning only.
- **A copied path is plain text without quotes:** its recipient is an agent, not a shell.
- **Tree rows render without appear animations** (empty `ItemContainerTransitions`), or a
  basket switch shows an empty tree for about a second.
- **The application icon is generated by `scripts/generate-icon.ps1`; the binary is never
  hand-edited.**
- **Testing policy:** the domain is covered by unit tests, the UI by one headless smoke
  run. A long multi-step UI scenario stays out of the repository — it is fragile and
  expensive to keep. The check seams (`PASTEHATCH_DATA_ROOT` and friends) exist so
  automated runs never appear on the user's desktop.
