Ограничение - не больше 1-2 предложений на требование
---

- **Локальное приложение** — лёгкая утилита для Windows, позволяющая быстро собирать временный контекст для AI-агентов без серверов и облачных сервисов.

- **Нативная Windows-платформа** — современное приложение для Windows на C#/.NET.

- **Нативные элементы интерфейса** — элементы управления являются нативными для Windows, размещаются как в прототипе и выполняют свои функции в приложении. Каждый элемент использует привычное для Windows поведение; неоднозначные решения выбираются через `prior-art-first` по официальным рекомендациям Microsoft, например по [контекстным меню](https://learn.microsoft.com/en-us/windows/apps/develop/ui/controls/menus-and-context-menus).

- **Работа из системного трея** — при закрытии окна приложение остаётся в области уведомлений Windows; правый щелчок по значку открывает меню с командой «Показать окно».

- **Корзины контекста** — каждая корзина представляет собой отдельную папку в `%LOCALAPPDATA%\PasteHatch\Baskets` и содержит все добавленные материалы; путь к каталогу пользователя приложение получает через `Environment.SpecialFolder.LocalApplicationData` ([документация Microsoft](https://learn.microsoft.com/dotnet/api/system.environment.specialfolder?view=net-10.0)).

- **Вкладки** — приложение поддерживает до 10 одновременно открытых корзин; щелчок переключает вкладку, двойной щелчок позволяет изменить её название. Новая корзина получает название по сокращённому дню недели и времени создания, например `Пн, 13:02`; при следующем запуске приложения восстанавливаются оставшиеся открытыми корзины и их содержимое.

- **Управление вкладками** — пользователь может создавать и закрывать корзины, пока не достигнут лимит в 10. Перед закрытием приложение запрашивает подтверждение; подтверждённая корзина отправляется в Корзину Windows вместе с папкой и файлами, а отмена оставляет её открытой.

- **Папка корзины** — каждой корзине назначается короткий UID; её путь можно просмотреть и открыть в Проводнике Windows.

- **Универсальная вставка** — когда окно приложения находится в фокусе, `Ctrl+V` автоматически добавляет содержимое буфера обмена в активную корзину.

- **Поддерживаемые данные** — скриншоты, изображения, обычный текст, ссылки и файлы. Приложение самостоятельно определяет тип содержимого и сохраняет его в подходящем формате.

- **Открытие материалов** — один щелчок выделяет элемент списка, а двойной щелчок открывает его в приложении Windows по умолчанию.

- **Переименование файлов** — имя файла можно изменить без изменения его расширения через контекстное меню или клавишу `F2`.

- **Удаление материалов** — перед удалением материала приложение запрашивает подтверждение, после которого файл отправляется в Корзину Windows.

- **Drag & Drop** — материалы можно добавлять простым перетаскиванием в окно приложения.

- **Автоматическое сохранение** — каждый добавленный элемент немедленно сохраняется отдельным файлом без диалогов, ручного выбора имени или подтверждений.

- **Быстрая текстовая заметка** — ввод текста и нажатие `Enter` создают файл `.txt` с именем по дню недели и времени, например `Пн, 13:02.txt`; название можно изменить, сохранив расширение.

- **Копирование пути** — абсолютный путь к папке активной корзины можно скопировать для передачи локальному AI-агенту.

- **Окно приложения** — приложение открывается в небольшом плавающем окне.

- **Изолированность корзин** — материалы каждой вкладки сохраняются в собственной папке; вставка и создание заметок всегда относятся к активной вкладке.
