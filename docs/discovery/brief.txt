---

- **Local application** — a light Windows utility for quickly gathering temporary context
  for AI agents, with no servers or cloud services.

- **Native Windows platform** — a modern Windows application on C#/.NET.

- **Native interface elements** — the controls are native to Windows, laid out as in the
  prototype and doing their job in the application. Every element uses familiar Windows
  behaviour; ambiguous choices go through `prior-art-first` on official Microsoft guidance,
  e.g. for [context menus](https://learn.microsoft.com/en-us/windows/apps/develop/ui/controls/menus-and-context-menus).

- **System tray work** — closing the window keeps the application in the Windows
  notification area; right click on the icon opens a menu with a "Show window" command.

- **Context baskets** — every basket is a separate folder in
  `%LOCALAPPDATA%\PasteHatch\Baskets` holding all added materials; the application gets the
  user catalog path through `Environment.SpecialFolder.LocalApplicationData`
  ([Microsoft docs](https://learn.microsoft.com/dotnet/api/system.environment.specialfolder?view=net-10.0)).

- **Tabs** — the application supports up to 10 simultaneously open baskets; a click
  switches the tab, a double click renames it. A new basket is named after the abbreviated
  weekday and creation time, e.g. `Пн, 13:02`; the next launch restores the baskets that
  stayed open and their contents.

- **Tab management** — the user can create and close baskets until the limit of 10 is hit.
  Before closing the application asks for confirmation; a confirmed basket goes to the
  Windows Recycle Bin with its folder and files, cancel keeps it open.

- **Basket folder** — every basket gets a short UID; its path can be viewed and opened in
  Windows Explorer.

- **Universal paste** — while the application window has focus, `Ctrl+V` automatically adds
  clipboard content to the active basket.

- **Supported data** — screenshots, images, plain text, links and files. The application
  detects the content type itself and saves it in a suitable format.

- **Opening materials** — one click selects the list item, a double click opens it in the
  default Windows application.

- **Renaming files** — the file name can be changed without touching its extension through
  the context menu or `F2`.

- **Deleting materials** — before deleting a material the application asks for
  confirmation, after which the file goes to the Windows Recycle Bin.

- **Drag & Drop** — materials can be added by simply dragging them into the application
  window.

- **Automatic save** — every added item is immediately saved as a separate file, with no
  dialogs, manual name choice or confirmations.

- **Quick text note** — typing text and pressing `Enter` creates a `.txt` file named after
  the weekday and time, e.g. `Пн, 13:02.txt`; the name can be changed while keeping the
  extension.

- **Copy path** — the absolute path of the active basket's folder can be copied to hand to
  a local AI agent.

- **Application window** — the application opens in a small floating window.

- **Basket isolation** — each tab's materials are saved in its own folder; pasting and note
  creation always target the active tab.
